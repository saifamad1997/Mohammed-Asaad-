# بروتوكول جسر التصميم CAD Bridge v1

هذا العقد هو صيغة التسليم الموحدة بين مهندس التصميم الذكي وإضافات AutoCAD وSketchUp Desktop. لا يعني وجود العقد أن اتصالاً حياً قد تم تفعيله؛ الاتصال الحي يحتاج إضافة محلية عاملة ومصادقة وقناة اتصال.

## مبادئ
- الوحدات القياسية: millimeter (mm)، والزوايا بالدرجات.
- كل قيمة رقمية يجب أن تكون معلومة من المستخدم أو ملف قياس موثوق. القيمة المجهولة تكون null ولا تُستبدل بقيمة افتراضية.
- كل تصميم يبدأ بحالة draft. لا يسمح بالتصنيع قبل موافقة المستخدم والتحقق الهندسي.
- المصدر الواحد هو DesignDraft؛ يحوّل كل Adapter نفس البيانات إلى أوامر البرنامج الخاص به.
- لا تنفذ الإضافات عمليات حفر أو قص أو وصلات تلقائية من بيانات غير مكتملة.

## Envelope
```json
{
  "protocol": "mo-asaad.cad-bridge",
  "version": 1,
  "draftId": "uuid",
  "createdAt": "ISO-8601",
  "status": "draft",
  "source": { "kind": "ai-assistant", "projectId": null },
  "units": { "length": "mm", "angle": "degree" },
  "design": {
    "kind": "sofa",
    "name": "مسودة كنباي",
    "description": "",
    "dimensions": { "width": null, "depth": null, "height": null },
    "materials": [],
    "components": [],
    "openQuestions": []
  },
  "targets": ["autocad", "sketchup"],
  "validation": { "readyForGeometry": false, "readyForManufacturing": false, "issues": [] }
}
```

## Component contract
كل عنصر يملك id ثابتاً وname وrole وdimensions (width/depth/height بالملليمتر أو null) وtransform اختياري. لا تُنشأ هندسة لعنصر ذي أبعاد ناقصة. يمكن أن تحمل العناصر metadata للمواد والتنجيد دون تحويلها تلقائياً إلى خصائص تصنيع.

## حالات الاتصال
- disconnected: لا توجد إضافة محلية متصلة.
- pairing: المصادقة/الاقتران قيد التنفيذ.
- connected: الإضافة متصلة ومستعدة لاستقبال مسودات.
- busy: البرنامج ينفذ مهمة.
- error: فشل اتصال أو تحويل.
كل Adapter يعلن اسم البرنامج وإصداره وإصدار البروتوكول وآخر heartbeat.

## سير التنفيذ
1. المساعد ينشئ DesignDraft ويعيده مع الرد.
2. النظام يتحقق من المخطط والوحدات والقيم المفقودة.
3. تعرض المسودة للمستخدم في النظام، مع أسئلة الاستكمال.
4. بعد اختيار البرنامج وإرسال أمر المستخدم، يرسل النظام envelope إلى Adapter المتصل.
5. يعيد Adapter jobId وحالة التنفيذ وملخص النتائج أو الأخطاء.
6. لا تتحول الحالة إلى approved أو manufacturing إلا بموافقة صريحة وفحوص مستقلة.

## مسؤوليات المحولات
- AutoCAD: تحويل المسودة إلى كيانات 2D/3D مدعومة، مع حفظ وحدات الرسم وبيانات المصدر. لا تدّعي إنشاء ملف DWG إلا بعد نجاح الحفظ.
- SketchUp Desktop: إنشاء مجموعات/مكونات من العناصر المكتملة، وإرفاق draftId وcomponentId كـ Attributes. لا تدّعي تجميعاً صحيحاً إذا غابت مواضع القطع أو قواعد الوصل.
- لا يعتمد هذا البروتوكول على SketchUp Web أو يزعم أن إضافات سطح المكتب تعمل داخله.

## الأمان
يجب أن يكون الاقتران برمز قصير مؤقت، واتصال TLS، ورمز جهاز قابل للإلغاء. لا تضع مفاتيح API في ملفات JSON أو الإضافات أو المستودع. لا تقبل أوامر من جهاز غير مقترن، ولا تسمح بفتح ملفات/مسارات محلية عشوائية من طلبات الشبكة.
