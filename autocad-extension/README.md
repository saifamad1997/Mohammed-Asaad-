# AutoCAD Desktop Adapter — DesignDraft v1

## ما يفعله هذا الإصدار
- يضيف الأمر `MA_IMPORT_DRAFT` إلى AutoCAD Desktop.
- يقرأ ملف JSON وفق `mo-asaad.cad-bridge` الإصدار 1.
- ينشئ Solid3d منفصلاً لكل عنصر تتوفر له أبعاد موجبة للعرض والعمق والارتفاع (بالملليمتر).
- يضع العناصر بجانب بعضها ككتل تصورية، ويكتب اسم العنصر أسفل الكتلة.
- يتجاوز العناصر التي ينقصها بُعد، ولا يخترع قيمة بديلة.

## البناء
1. ثبّت Visual Studio أو .NET SDK المناسب لإصدار AutoCAD لديك.
2. افتح ملف `MohammedAsaad.CadBridge.csproj`.
3. اضبط الخاصية `AutoCADManagedDir` إلى مجلد تثبيت AutoCAD الذي يحتوي AcCoreMgd.dll وAcDbMgd.dll وAcMgd.dll.
4. طابق TargetFramework مع إصدار AutoCAD و.NET المدعومين في جهازك قبل البناء؛ قد تحتاج تغييره حسب إصدار AutoCAD.
5. ابنِ المشروع، ثم حمّل DLL الناتج عبر الأمر NETLOAD في AutoCAD.
6. شغّل الأمر `MA_IMPORT_DRAFT` واختر ملف المسودة JSON.

## الحدود الحالية
- هذا محول أولي لاستيراد ملف يختاره المستخدم يدوياً، وليس اتصالاً حياً بالموقع.
- ينشئ كتل 3D منفصلة فقط؛ لا ينشئ وصلات أو ثقوباً أو مفصلات أو سككاً أو تجميع أثاث تلقائياً.
- لا يحفظ DWG تلقائياً ولا يدّعي ذلك؛ احفظ الرسم من AutoCAD بعد مراجعته.
- لم يُبنَ أو يُختبر على نسخة AutoCAD فعلية في هذه المرحلة.
- لا تعتمد الناتج للتصنيع قبل مراجعة مهندس/فني واعتماد الأبعاد والوصلات والخلوصات.
