# جسر SketchUp — محمد أسعد للتنجيد والتصميم الهندسي

## ما الذي يفعله الإصدار الأول؟
- يستورد ملف JSON الذي يصدره قسم SketchUp في نظام الشركة.
- يقرأ كتالوج التصنيع المحفوظ داخل المشروع.
- ينشئ كل قطعة من قائمة القص كمكوّن SketchUp مستقل وبسماكة اللوح المسجلة.
- يحفظ اسم القطعة وأبعادها وبيانات مصدرها داخل Attributes.

## ما الذي لا يفعله بعد؟
هذا الإصدار لا يستنتج أماكن تركيب القطع ولا ينشئ خزانة مجمعة تلقائياً. قائمة القص الحالية تحتوي أبعاداً وكميات فقط، ولا تحتوي مواضع XYZ أو علاقات التجميع أو تفاصيل المفصلات والسكك والثقوب. لذلك يعرض القطع منفصلة في مساحة منظمة ولا يجوز اعتبار الناتج رسماً تصنيعياً معتمداً.

## تثبيت الإضافة في SketchUp Desktop
1. انسخ الملف `mo_as_sketchup_bridge.rb` إلى مجلد Plugins الخاص بإصدار SketchUp.
2. أغلق SketchUp وافتحه مجدداً.
3. من قائمة Extensions اختر «محمد أسعد | استيراد مشروع الشركة».
4. من نظام الشركة افتح صفحة SketchUp، ثم اضغط «تصدير بيانات المشروع» بعد حفظ كتالوج التصنيع.
5. اختر ملف JSON الناتج داخل SketchUp.

## مسار الويب
افتح SketchUp Web وسجّل الدخول بحساب Trimble. استيراد DAE وملفات النماذج الأخرى يعتمد على نوع الاشتراك. هذا الجسر Ruby مخصص لنسخة Desktop ولا يعمل داخل المتصفح.

## متطلبات المرحلة التالية
إضافة بيانات تموضع كل قطعة، ونوع الحافة، واتجاه العروق، والثقوب، والمفصلات، والسكك، وقواعد التجميع حسب نوع الأثاث قبل توليد موديل مجمّع أو أوراق تصنيع نهائية.
